## 核心判断

这个产品不应被定义为“带 AI 的写作编辑器”，而应定义为“AI 原生的长篇文学创作工作台”。它的核心资产不是某一次生成的正文，而是围绕一部作品持续沉淀的创作记忆：题材承诺、世界规则、人物动机、关系网络、剧情因果、伏笔状态、文风范式、读者反馈和作者偏好。

平台的关键竞争力也不只是“写得快”，而是能在长篇、连载、多卷、多角色、多伏笔的复杂创作中稳定维持一致性、可控性和可修改性，让作者从一次性 prompt 迁移到可持续的创作工程。
