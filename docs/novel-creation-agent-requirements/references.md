# 参考资料

## 1. 网络文学行业与趋势

### R1. 2025 中国网络文学发展研究报告

- 来源：中国社会科学网
- 链接：https://www.cssn.cn/skgz/bwyc/202604/t20260420_5981165.shtml
- 参考要点：网络文学继续保持繁荣发展；截至 2025 年底网络文学用户规模约 5.26 亿；网络文学在创作开发、全球传播、IP 价值链和 AI 技术赋能方面持续发展。

### R2. 2024 中国网络文学发展研究报告发布

- 来源：国家新闻出版署
- 链接：https://www.nppa.gov.cn/xxfb/ywdt/202505/t20250512_894767.html
- 参考要点：网络文学作者规模、用户规模、主流化精品化趋势；传统文化元素、IP+文旅、AI 赋能等成为创作和产业亮点。

### R3. 2024 中国网络文学蓝皮书

- 来源：南京市文化和旅游局转载
- 链接：https://wl.nanjing.gov.cn/pwwh/202507/t20250703_5599775.html
- 参考要点：网络文学用户规模、共读共创生态；同时指出创作均质化、套路化、人物扁平、类型融合表面化、融梗抄袭和大量作品未完成等问题。

## 2. 文学与创作方法

### R4. Aristotle, Poetics

- 来源：The Internet Classics Archive, MIT
- 链接：https://classics.mit.edu/Aristotle/poetics.1.1.html
- 参考要点：戏剧/叙事质量可从情节、人物、语言、思想、景观、音乐等要素分析；本次抽象为作品质量维度时重点参考“情节、人物、语言、思想”。

### R5. Fantasy Worldbuilding Questions

- 来源：Science Fiction & Fantasy Writers Association
- 链接：https://sfwa.org/2009/08/04/fantasy-worldbuilding-questions/
- 参考要点：世界观构建需要围绕历史、地理、文化、社会结构、规则和生活细节提问；不是所有问题都必须回答，但问题清单能帮助作者建立可信世界。

### R6. Royal Road Chapters Knowledge Base

- 来源：Royal Road
- 链接：https://www.royalroad.com/support/knowledgebase/83
- 参考要点：连载章节有平台化长度和阅读体验要求；该站建议章节少于 10000 词，约 2000 词常是较好的停点。用于说明连载平台的章节节奏需要产品化支持。

## 3. AI 写作竞品和创作工具

### R7. NovelAI Memory / Author's Note

- 来源：NovelAI Documentation
- 链接：https://docs.novelai.net/en/text/editor/storysettings/
- 参考要点：Memory 用于保存希望 AI 记住的故事、角色和已发生事件；Author's Note 用于更贴近当前上下文地影响输出。该产品形态说明 AI 写作中的“可控上下文”是核心能力。

### R8. Novelcrafter Codex

- 来源：Novelcrafter
- 链接：https://www.novelcrafter.com/features/codex
- 参考要点：Story Bible/Codex 用于组织角色、地点和设定，并提供智能高亮、重复表达、AI 写作模式和对白控制等编辑辅助。

### R9. Plottr

- 来源：Plottr
- 链接：https://plottr.com/
- 参考要点：视觉时间线、人物表、世界构建、系列圣经和模板是成熟写作工具的关键能力；尤其适合长篇和系列作品管理。

## 4. Agent 与长期记忆

### R10. Generative Agents: Interactive Simulacra of Human Behavior

- 来源：arXiv
- 链接：https://arxiv.org/abs/2304.03442
- 参考要点：生成式 agent 通过观察、记忆、反思和规划产生可信行为；对小说角色模拟、创作复盘和 agent 记忆架构有启发。

### R11. MemGPT: Towards LLMs as Operating Systems

- 来源：arXiv
- 链接：https://arxiv.org/abs/2310.08560
- 参考要点：通过分层记忆和虚拟上下文管理突破模型上下文窗口限制；对长篇作品的上下文装配和记忆分层设计有直接参考价值。

### R12. Memory for Autonomous LLM Agents: Mechanisms, Evaluation, and Emerging Frontiers

- 来源：arXiv
- 链接：https://arxiv.org/html/2603.07670v1
- 参考要点：将 agent 记忆形式化为 write-manage-read 循环，并从时间范围、表示形式和控制策略等维度分析记忆系统。适合指导小说平台的记忆写入、管理和读取闭环。

## 5. 合规与版权

### R13. Copyright and Artificial Intelligence

- 来源：U.S. Copyright Office
- 链接：https://www.copyright.gov/ai/
- 参考要点：美国版权局关于 AI 和版权的系列报告，包括 2025 年发布的生成式 AI 输出可版权性部分；用于提示产品需要记录人类创作贡献，不能简单承诺 AI 输出版权。

### R14. 生成式人工智能服务管理暂行办法

- 来源：中央网络安全和信息化委员会办公室
- 链接：https://www.cac.gov.cn/2023-07/13/c_1690898327029107.htm
- 参考要点：面向中国境内公众提供生成式 AI 服务需关注合法合规、内容安全、权益保护和分类分级监管等要求。

### R15. 人工智能生成合成内容标识办法

- 来源：中央网络安全和信息化委员会办公室
- 链接：https://www.cac.gov.cn/2025-03/14/c_1743654684782215.htm
- 参考要点：AI 生成合成内容包括文本、图片、音频、视频、虚拟场景等；标识包括显式标识和隐式标识。小说创作平台如果提供生成服务和发布能力，需要预留标识、记录和溯源能力。
